# 🤖 LandAgencyMvc Telegram Remote Code Assistant

Автономний фоновий Telegram-бот для віддалених консультацій щодо кодової бази проєкту `LandAgencyMvc` прямо зі смартфона.

---

## 🚀 Можливості бота

1. **Розуміє всю архітектуру та код LandAgencyMvc**:
   - Автоматично індексує контролери (`Controllers/*.cs`), моделі (`Models/*.cs`), сервіси (`Services/*.cs`) та Razor-шаблони (`Views/**/*.cshtml`).
   - На запити на кшталт *«Як змінити кнопку в Catalog.cshtml?»* знаходить релевантні файли, підтягує реальний код і формує точну відповідь.
2. **Працює непомітно у фоні на Mac**:
   - На екрані MacBook не відкривається жодних вікон — ви спокійно працюєте над іншими задачами.
3. **Зручний інтерфейс у Telegram**:
   - Підтримка діалогу з контекстом попередніх повідомлень.
   - Команди: `/start`, `/help`, `/files` (список проіндексованих файлів), `/cat <шлях>` (перегляд вмісту файлу), `/clear` (очищення контексту розмови), `/status` (стан бота).
4. **Безпека**:
   - Опціональний Whitelist за Telegram User ID (`ALLOWED_TELEGRAM_USER_IDS`), щоб ніхто сторонній не міг запитувати інформацію про ваш проєкт.

## 🛠️ Швидкий старт за 3 кроки

### Крок 1. Отримайте токен Telegram-бота
1. У Telegram відкрийте бота **[@BotFather](https://t.me/BotFather)**.
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я (наприклад, `LandAgency Assistant`) та юзернейм бота (наприклад, `my_landagency_assistant_bot`).
4. Скопіюйте наданий токен (формат: `123456789:ABCdefGhIJKlm...`).

### Крок 2. Отримайте безкоштовний ключ Gemini API
1. Перейдіть на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Натисніть **Create API key** і скопіюйте отриманий ключ.

### Крок 3. Налаштуйте `.env` та запустіть бота
1. Відкрийте файл `tools/telegram_assistant/.env` у текстовому редакторі (або запустіть `./run.sh`, він створить його автоматично).
2. Вставте отримані токени:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_від_botfather
GEMINI_API_KEY=ваш_ключ_від_google_ai_studio
```
3. Запустіть бота у фоновому режимі:
```bash
cd tools/telegram_assistant
./run.sh start
```

## 📱 Керування ботом

Всі команди виконуються з папки `tools/telegram_assistant/`:

- `./run.sh start` — запустити бота у фоні (буде працювати навіть при закритому терміналі).
- `./run.sh status` — перевірити, чи бот активний.
- `./run.sh logs` — переглянути останні логи та запити в реальному часі (`Ctrl+C` для виходу).
- `./run.sh stop` — зупинити фонового бота.
- `./run.sh run` — запустити в інтерактивному режимі безпосередньо у терміналі (для налагодження).

Тепер ви можете відкрити Telegram на телефоні, знайти свого бота та запитати будь-що про проєкт!
